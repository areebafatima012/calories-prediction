# 🔥 Calories Burn Prediction Project

## 📌 Project Description
This is a Machine Learning project built using Streamlit that predicts calories burned based on user input data.

## 🚀 Features
- Real-time calorie prediction
- Interactive Streamlit UI
- Data visualization
- Machine learning model using XGBoost

## 🛠 Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- XGBoost

## 📊 Files Included
- app.py (main application)
- calories.csv (dataset)
- calories_prediction_project.ipynb (model training notebook)

## ▶️ How to Run
```bash
streamlit run app.py
